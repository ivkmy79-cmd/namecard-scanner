☁️ 구글 주소록 자동 등록

      
확인 중…

      
설정해 두면 버튼 한 번으로 구글 주소록에 바로 등록되고, 폰 주소록에 자동 동기화됩니다. 파일도 공유 화면도 거치지 않습니다.


      

        
        
      

      

        
        
      

      

      

        ▸ 설정 방법 (10분, 무료 · 한 번만)
        

          아래 4번에서 넣을 이 앱의 주소입니다.

          
          
        

        
    
          
  1. console.cloud.google.com 접속 → 로그인
    2. 
          
  2. 검색창에 People API → 열고 사용 클릭
    3. 
          
  3. 좌측 API 및 서비스 → OAuth 동의 화면
    
              User Type 외부 → 앱 이름·이메일만 채우고 저장
    
              테스트 사용자에 본인 지메일 주소 추가
    4. 
          
  4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
    
              애플리케이션 유형 웹 애플리케이션
    
              승인된 JavaScript 원본에 위의 주소를 그대로 추가
    5. 
          
  5. 만들어진 클라이언트 ID를 복사해 위 칸에 붙여넣고 ID 저장
    6. 
          
  6. 구글 계정 연결 클릭 → 구글 로그인 → 권한 허용
    7. 
        

        
"이 앱은 확인되지 않았습니다" 경고가 뜨면 고급 → (앱 이름)(으)로 이동을 누르세요. 본인이 만든 앱이라 정상입니다.

      

    


    

      
🤖 인식 엔진 설정

      
확인 중…


      

        
        
      


      

        
        
        

      

      
키는 이 폰 안에만 저장됩니다. 엔진마다 따로 보관되니 여러 개 넣어두고 바꿔가며 쓰셔도 됩니다.


      

        
        
      

      

      

        ▸ Groq 키 발급 방법 (3분, 카드 불필요)
        
    
          
  1. console.groq.com 접속 → 구글 계정으로 로그인
    2. 
          
  2. 왼쪽 메뉴 API Keys → Create API Key
    3. 
          
  3. 이름은 아무거나(예: namecard) 입력 후 만들기
    4. 
          
  4. gsk_… 로 시작하는 키 전체 복사 — 이 화면을 닫으면 다시 볼 수 없습니다
    5. 
          
  5. 위 칸에 붙여넣고 저장 → 연결 시험
    6. 
        

        
Qwen3.6-27B 멀티모달 모델을 씁니다. 한국어·베트남어에 강하고, 이미지를 넣으면 항목별로 정리된 결과를 바로 돌려줍니다.

      


      

        ▸ OCR.space 키 발급 방법 (1분)
        
    
          
  1. ocr.space/ocrapi/freekey 접속
    2. 
          
  2. 이메일 주소만 입력하고 신청
    3. 
          
  3. 메일로 온 K… 키를 복사
    4. 
          
  4. 위 칸에 붙여넣고 저장 → 연결 시험
    5. 
        

        
글자만 뽑아주고 항목 분류는 앱이 합니다. 월 25,000회 무료. Groq이 막혔을 때의 예비용으로 좋습니다.

      


      

        ▸ Gemini 키 발급 방법
        
    
          
  1. aistudio.google.com/apikey → Create API key
    2. 
          
  2. 위 칸에 붙여넣고 저장 → 연결 시험
    3. 
        

        
2026년 8월 기준 Gemini API는 결제 계정을 연결해야 동작합니다. 무료 등급으로는 모든 모델이 403으로 거부됩니다.

      

    


    

      
📱 폰 주소록에 저장하기

      
구글 주소록 자동 등록을 설정해 두셨다면 아래 과정이 필요 없습니다. 버튼 한 번이면 끝나고 폰에 자동으로 들어옵니다.

      
    
        
  1. 명함을 촬영하고 글자 인식 시작을 누릅니다.
    2. 
        
  2. 인식 결과를 확인·수정합니다.
    3. 
        
  3. 저장하고 주소록에 추가를 누릅니다.
    4. 
        
  4. 공유 화면이 뜨면 목록에서 연락처를 고르세요. 바로 등록됩니다.
    5. 
        
  5. 공유 화면 대신 파일이 내려받아졌다면, 그 파일을 눌러 여세요.
    
            아이폰: "새로운 연락처 생성"이 뜹니다.
    
            안드로이드: 연락처 앱이 열리며 가져오기가 진행됩니다.
    6. 
        
  6. 둘 다 안 되면 정보를 복사하는 창이 뜹니다. 복사해서 연락처 앱에 붙여넣으세요.
    7. 
      

    


    

      
❗ 주소록 추가가 안 될 때

      
기기와 브라우저마다 동작이 달라서, 앱이 아래 순서로 자동 전환합니다.

      
    
        
  1. 공유 화면으로 연락처 앱에 바로 전달 (가장 확실)
    2. 
        
  2. .vcf 파일 내려받기 → 파일을 눌러 열기
    3. 
        
  3. 정보 복사 → 연락처 앱에 붙여넣기
    4. 
      

      
아이폰 홈 화면 앱에서는 애플 정책상 파일 저장이 막혀 있습니다. 공유 화면이 안 뜨면 사파리로 이 주소를 열어 시도해 주세요.

      
여러 장을 한꺼번에 넣는 편이 훨씬 편합니다. 저장 목록 → 전체를 주소록에 추가를 쓰시거나, 아래 구글 주소록 방법을 쓰세요.

    


    

      
🌐 구글 주소록에 한꺼번에 넣기

      
    
        
  1. 여러 장을 찍어 저장 목록에 모읍니다.
    2. 
        
  2. 전체 주소록 파일(.vcf) 내려받기를 누릅니다.
    3. 
        
  3. PC나 폰 브라우저에서 contacts.google.com 접속
    4. 
        
  4. 왼쪽 메뉴 → 가져오기 → 내려받은 .vcf 파일 선택
    5. 
        
  5. 구글 주소록에 들어가면 폰에도 자동 동기화됩니다.
    6. 
      

      
웹 브라우저는 보안상 주소록에 직접 쓸 수 없습니다. 그래서 파일로 내보내 가져오는 방식이 표준이며, 어느 기기에서나 동작합니다.

    


    

      
📲 앱처럼 설치하기

      
안드로이드 (크롬)

      주소창 오른쪽 ⋮ → 앱 설치 또는 홈 화면에 추가

      
아이폰 (사파리)

      화면 하단 공유 버튼 → 홈 화면에 추가 → 추가

      
아이폰은 반드시 사파리로 열어야 홈 화면 추가가 됩니다. 크롬이나 카카오톡 내장 브라우저에서는 메뉴가 보이지 않습니다.

    


    

      
📶 오프라인으로 쓰기

      
촬영·인식 모두 폰 안에서 처리되므로, 인식에 필요한 데이터를 한 번만 받아두면 비행기모드에서도 쓸 수 있습니다.

      
    
        
  1. 인터넷이 되는 곳에서 촬영 탭의 선택한 언어 미리 받기를 누릅니다.
    2. 
        
  2. 완료 메시지가 뜨면 준비 끝. 이후에는 인터넷 없이도 인식이 됩니다.
    3. 
        
  3. 언어 선택을 바꾸면 그 언어는 다시 한 번 받아야 합니다.
    4. 
      

    


    

      
🎯 인식률을 높이는 요령

      
    
        
  • 밝은 곳에서, 그림자가 지지 않게
    • 
        
  • 미리보기 틀이 명함 실물 비율(90×50mm) 입니다. 네 모서리를 틀에 맞추세요
    • 
        
  • 명함이 화면을 가득 채우도록 가까이
    • 
        
  • 카메라를 수직으로 — 비스듬하면 크게 떨어집니다
    • 
        
  • 배경은 어두운 단색이 좋습니다 (책상 위 검은 수첩 등)
    • 
        
  • AI 인식은 비스듬한 각도·복잡한 배경에도 강합니다. 잘 안 될 때 먼저 확인할 것은 초점입니다
    • 
        
  • 전화번호·이메일은 정확도가 높고, 이름·회사명은 확인이 필요한 경우가 많습니다
    •
